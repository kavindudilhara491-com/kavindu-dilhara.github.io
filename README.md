# Kavindu Dilhara - Cyber Security Portfolio

## Files
- `index.html` - website structure/content
- `style.css` - complete styling/responsive design
- `script.js` - mobile menu, scroll effects, active navigation, contact-form demo

## Run
Open `index.html` in a browser, or use VS Code + Live Server.

## Personalize
1. In `index.html`, replace GitHub/LinkedIn/email `#`/placeholder links with your real links.
2. Your uploaded profile photo is included as `assets/profile.png` and is used in both the profile card and About Me photo section.
3. Your uploaded CV is included as `assets/Kavindu-Dilhara-CV.pdf`.
4. Replace project descriptions and GitHub links with your real repositories.
5. The contact form is front-end only. For real messages, connect it to a backend/email service.
